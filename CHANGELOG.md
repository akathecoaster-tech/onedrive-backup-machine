# Changelog

## [1.0.0] - 2026-07-31

### Added
- Public Supervisor add-on repository for OneDrive Backup Machine.
- Local HTTP API compatible with `augleao/onedrive-backup-machine-integration`.
- Microsoft device-code login via MSAL.
- Task list with cron schedules.
- Full and incremental download modes.
- Web UI for status, login, tasks, and recent jobs.
- Fresh history with no legacy credentials or add-on secrets.
